# Crack sweep: every live site against ratings.json, 23 November 2026

design.b.rounds@SovereignWebsite.dinis, about 13:50 UTC, for design.b, at Dinis's request. The rule in [the maturity model](https://github.com/SovereignWebsite/Site__Agents__Design/blob/dev/docs/maturity.md): "A site that reaches M1 and is missing from ratings.json or from the hub is a defect."

## How

Three lists of addresses, merged and then each fetched live (GET /, 15 s timeout):
1. **The IaC requests.** SovereignWebsite__IaC, `requests/*/site.json`, 57 requests. Each address is `label.group.domain`, with sovereignweb.site where no domain is given.
2. **The hub's own list,** https://hub.sovereignweb.site/sites.json (34 sites).
3. **ratings.json** (21 sites before this sweep).

I could not see the DNS zones for sovereignweb.site or agenticcells.site from here, so names that are only in DNS are not covered. The GitHub repositories I can see (117, under SovereignWebsite, AgentiCCells, SGit-AI, PrompTugal and SHarness-AI) were used as a cross-check, not as a source of addresses: a repository is not a live site.
