## How to make it vibrant (all five)

- **Colour:** start from the company's own palette (below), with one saturated accent used boldly: a full-bleed hero band, not a thin rule.
- **Type with character, still system fonts:** a display size of `clamp(2.8rem, 9vw, 6rem)` at weight 800 or 900 for one line; a serif (Georgia, "Iowan Old Style") or `ui-monospace` where the company's own site uses one; tight leading (1.0) on display lines only.
- **Motion where it helps:** CSS only, short (under 600 ms), and none under `prefers-reduced-motion`. For example, a diagram that draws itself, or ciphertext that resolves to text.
- **The company's own facts, drawn:** each site has numbers and a sequence. Draw them as the hero idea, not as a row of stat cards.
