## Last changes, if there is time before 08:00

1. **/swarm/ is not in the site's shell.** It has its own stylesheet (swarm.css), its own header and navigation, and the full three-sentence disclaimer. The critic said it "breaks the system". Give it the shared header and the one-line disclaimer.
2. **/swarm/ repeats one link text 19 times:** "The team inside the site, on Mistral: seven roles on pipeline-demo". A screen reader user hears 19 identical links. Make each run's link name its run, for example "Run 3, 20 November 23:12: plan, edit, review". Group the runs in a table (time, roles, calls, tokens, result), with the replay link in the last column.
3. **Show that the code scrolls.** On a phone, a still view of the console looks cut off. Add a right-edge fade on `.codebox` while it can scroll (`mask-image:linear-gradient(to right,#000 85%,transparent)`), and a small "Scroll for more →" under it on phones only.
4. **Design 2's footnotes:** a lone "5" wraps onto its own line, and the source list has a stray ";". Keep a marker with its word (`white-space:nowrap` on the last word and its `sup`), and fix the separator.
5. **The poster:** the venue and the join link still come from the organisers. If Dinis has given you a public link, put it in the poster; if not, leave the poster as it is.
6. **Smaller:**
